# Render Validation

Ainda não há limiar de similaridade aprovado.

## Método obrigatório

Comparar MAME e OpenGL no mesmo frame lógico e resolução interna normalizada. Separar diferenças de composição de diferenças cosméticas de saída.

O limiar será definido somente depois que o harness produzir pares reais MAME/port e for demonstrado que o método detecta divergências funcionais sem gerar falsos positivos excessivos.
