# State Map

Ainda não existe um mapa de estado validado contra o MAME.

## Regra

Novos endereços/campos só entram aqui após confirmação pelo driver CPS1, debugger/API do MAME ou evidência equivalente autorizada pelo contrato de AGENTS.md.

## Campos planejados

- posição X/Y dos jogadores;
- estado da máquina de estados;
- frame de animação;
- hitboxes/hurtboxes;
- vida;
- timer;
- RNG;
- decisão da IA;
- câmera/scroll;
- eventos de áudio.
